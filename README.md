## Entry

> **unhinged**

Length: 8 characters (gate: 1–30 characters).

## Why this word

The whole internet in one word: **unhinged**. It is funny on its own — the internet's own favourite self-description — and true of the internet as a whole rather than one app, site or mood: feeds, comments, livestreams, group chats and marketplaces all run on the same unfiltered energy. It surprises where the obvious reaches ("cats", "memes", "chaos") do not, and it lands in a single beat: eight letters, instantly readable. The reader laughs, then nods.

## Run

```sh
node main.ts
```

Writes the entry word to `/output/entry.txt`.
